# Bennys Big Race

Bennys Big Race is a fast paced arcade racwer built in godots game engine where starting in any place but last
is impossible the goal of this game is to try and bounce back from last to first place

in this you race against 11 other people so in total 12 cars there are parts of the track that 
will change as time goes on such as parts will become bouncy or completly shut off
